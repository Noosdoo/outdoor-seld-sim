# 名前付き評価シナリオ 追加5種の幾何設計（2026-07-17）

方針: すべて**評価専用**（fold2_room4〜8トークン、各20本、計100本）。学習・fold2本体・
fold3には一切触れない → v9.1の土俵と再学習は不変。既存の交差点サイレン（room9）と
合わせて6シナリオ体制。ablationでは各armをこの6シナリオでも採点し、
「物理要素Xを消すとシナリオYで何が壊れるか」を物語として示す。

共通規約（v9.1から継承）: マイク高1.5m・歩行1.0〜1.4m/s・法規音量較正・
暗騒音40〜65dB(A)（S5のみ例外）・相対CPA基準・記録列とscene.json全記録。

## S1 踏切通過（fold2_room8, scenario='crossing_wait'）

「警報の鳴る踏切の手前で立ち止まる。その背後から車が来る」— 大音量警告音の
マスキング下で車を拾えるかの物語。

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| マイク | 踏切へ歩行→**警報機の手前で停止**（停止時刻 U(3,5)s、3点折れ線） | 交差点シナリオと同じ停止規約 |
| 警報機 | 停止位置の前方 U(2.5,4.0)m・横 ±U(1.0,2.0)m・高さ2.5m、全長鳴動 | 高さ=規格（既知）。待機距離は設置実態の**仮定**と明記 |
| 車 | 背後から同方向 U(3,8)m/s、相対CPA U(1.55,3.0)m=注意層、t_cpa U(6,9)s | 踏切直前は一時停止義務（道路交通法33条）→減速接近の想定。等速近似は限界に注記 |
| 採点 | 踏切通知20/20の確認＋**マスキング下の車の検出・通知リードタイム**（オラクル併記） | |

## S2 背後からの自転車ベル（fold2_room7, scenario='bell_overtake'）

「歩道を歩いていると、後ろから自転車がベルを鳴らして追い越す」— 視覚が効かない
真後ろ→方位反転の最難関幾何。

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| マイク | 直線歩行 U(1.0,1.4)m/s | 既存規約 |
| 自転車 | 同方向後方から U(3,7)m/s（接近速度=差分1.6〜6m/s）、**側方間隔 U(0.8,1.5)m** | 速度=既存クラス値。側方間隔は改正道交法の「1m程度・1.0-1.5m目安」（車→自転車）をアンカーに借用。自転車→歩行者の明文数値なしは**仮定**と明記 |
| ベル | t_on = t_cpa − U(2,5)s から U(2,6)s 鳴動（クリップ内にクランプ）、単打:引き打ち=50:50、**取付高さ U(0.9,1.1)m（ハンドル位置の仮定）** | 「追い越し前に鳴らす」目的からの設計仮定 |
| t_cpa | U(6,9)s | 車と同じ「接近の頭を収める」規約 |
| 採点 | ベル通知率・**初動方向**（真後ろ±180°付近）・リードタイム | |

## S3 駐車場のバック車（fold2_room6, scenario='backup_reverse'）

「バック音を鳴らしながら車が自分に向かって下がってくる」— 警告音が車の危険を
代弁する実証（音源2つが同一軌道）。

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| マイク | 静止10本／歩行10本 | 既存規約 |
| 車（後退） | U(1,3)m/s、**後退方向±xランダム**、相対CPA=重大層 U(0.6,1.5)m×10本・注意層 U(1.55,3.0)m×10本、t_cpa U(6,9)s | 後退速度=既存研究値 |
| バック音 | **車と同一軌道**（車体の音）、全長鳴動（後退中は鳴り続ける） | Back-up beeper仕様（既知） |
| 採点 | beep通知リードタイム vs 相対CPA（重大層で2.5s前に間に合うか）＋車とbeepの方位一致 | |

> ⚠️**舞台=日本の適合性監査による訂正（2026-07-21、md/audit/舞台日本の適合性監査_2026-07-21.md）**:
> 後退時警報装置（車両後退通報装置）は日本の保安基準第145条の6で**乗車定員10人以上の
> バス・車両総重量3.5t超のトラックのみ**に装備義務があり、**普通乗用車には義務がない**。
> このシナリオの想定車種は「駐車場の普通乗用車」ではなく**大型車両（配送トラック・
> バス等）**と読み替える。エンジン音自体は現行のcar_drive音源を暫定使用（大型車固有の
> 低いエンジン音色は未実装、限界として明記）。音量規約も同基準（60-92dB@1m、旧87-112dB@1.2m
> は米OSHA基準の誤用）に修正が必要（--v93、precheckで完全不可聴率0%→32.59%と判明——
> 全量再生成・再学習は本人判断待ち）。

## S4 完全静穏＝純負例（fold2_room5, scenario='silent_negative'）

「音源が何もない街」— 誤通知率の最も綺麗な測定枠。今日発見した**車の幻覚の定量**に直結。

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 音源 | **なし**（暗騒音のみ U(40,65)dB(A)） | 誤通知のフロア測定 |
| マイク | 静止10本／歩行10本 | |
| 採点 | 全クラスの誤検出フレーム・誤通知/時（車幻覚率の主測定） | |
| 実装注記 | PSELDNetsが空ラベルを読めないため、**Colab側コピーのみ**frame0にダミー行1行を置く（採点は必ずscene.json基準。ダミーはローカルのGTに存在しない=文書化） | mix035の教訓 |

## S5 悪条件サイレン（fold2_room4, scenario='siren_worstnoise'）

「幹線道路級の騒音の中、遠くからサイレン」— 検出限界カーブの物語版。

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 暗騒音 | **U(60,65)dB(A) 固定**（上限帯に張り付け） | 環境基準の沿道60dB＋上振れ実態 |
| サイレン | peepo:wail=50:50、横距離 U(10,15)m、U(8,15)m/s、t_cpa U(6,9)s、全長鳴動 | 連続吹鳴の例外規約（交差点と同じ） |
| マイク | 静止10本／歩行10本 | |
| 採点 | 初検出時の距離・リードタイム（**オラクル併記**=物理限界と分離）・方向誤差 | |
