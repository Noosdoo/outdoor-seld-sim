## 1. 撮れ高リスト（計60本、優先度順。各10秒以上/テイク）

### A. 走行車の接近・通過 20本（ablation判別の主力）
- C1静穏路 10本＋C2交通量路 10本。**速度と横距離を意図的に散らす**
  （徐行/約30/約40km/hの目視3段×横2-15m）→ ドップラー・距離減衰・反射のarm差が出る構成

### B. 弱点マップ連動 20本（v11のN系ベースラインと直接比較）
- **EV/HV接近 5本**（車種メモ必須。N2=16%の実世界検証。スーパー駐車場出口・住宅街が狙い目）
- **停車→発進 5本**（駐車場。N7反応0.95sの実証）
- **自転車の至近通過 5本**（ベルは鳴らせないので走行音中心。自然にベルが鳴ったら最優先で記録）
- **見通し不良の角からの出現 5本**（塀・建物のある交差点。N1リード1.48sの実測対応物）

### C. 環境音・負例 10本（幻覚0/650と誤通知0.86回/時の実世界試験）
- 純静穏3・高騒音（繁華街/工事）3・雨上がり路面2・風あり2（風速メモ、3m/s超は不採用）

### D. 固定音源・機会音源 10本
- 実在踏切の警報 4本（S1/踏切200の実対応物）
- 実サイレンの自然遭遇（救急車等）: **遭遇したら他を中断して最優先記録**（計画的再生はしない）
- 残りはバック音（トラック後退）・クラクション等の自然発生で埋める

## 5. 超音波（不可聴帯）収録の機材追補（2026-08-12、本人質問への回答として整理）

- **主受信=H3-VR本体を96kHz収録**（ナイキスト48kHz・Lo Cutオフ）。メインアレイと
  同一機材で「方向つき4ch＋超音波帯」を1台で記録する。E2の検出器（帯域エネルギー×
  バースト周期性）は較正不要設計のため、40kHz感度が仕様外でもSNRが取れれば機能する
- **限界の明示**: H3-VRのマイク感度仕様は20kHzまでで40kHzは無保証。
  だから実地試行の第1測定項目は「H3-VRの40kHz実効感度」
- **送信側（統制試行用）**: 超音波距離センサモジュール（HC-SR04等・40kHz・数百円）
  を統制ピング送信機として使用
- **受信の保険**: 【2026-08-12訂正】バットディテクターは実売2.9万円〜と高価なため
  撤回（実録機材リサーチ_2026-08-12.md 4節）。保険・可聴化デモとも
  **ソフトウェアヘテロダイン（E2ミニ実装済み・無料）**で代替する
- 本格的な超音波計測（超音波MEMS＋192kHz）は卒論スコープ外＝将来課題と明記

## 6. 場所の決め方テンプレと0円構成（2026-08-13追記、本人の懸念への回答）

### 6.1 撮れ高→場所タイプ→許可の対応（固有名詞は下見で確定）

| 撮れ高 | 場所タイプ | 許可 |
| --- | --- | --- |
| A統制（車・発進・ベル・ブザー・クラクション） | 大学の駐車場/構内舗装地（大壁面から20m以上） | 要（指導教員経由で管理部門へ。相談事項としてスモーク計画§5に登録済み） |
| C1静穏路の走行車 | 大学周辺の歩道なし生活道路（30km/h帯） | 不要（公道・通行妨げない・会話除外規約） |
| 見通し不良の角 | 住宅街のブロック塀があるT字路/十字路、歩道側から | 不要（同上） |
| EV/HV接近 | スーパー駐車場出口の**公道側歩道**から | 不要（私有地内に入るなら一声） |
| 停車→発進 | 大学駐車場（A統制と同日に消化） | Aに含む |
| 繁華街負例 | 駅前商店街の歩道 | 不要 |
| 純静穏負例 | 静かな住宅街/公園（早朝・夜） | 不要（公園は掲示に従う） |
| 踏切 | 最寄りの実在踏切（時刻表どおり来る） | 不要（踏切から安全距離） |
| サイレン機会捕捉 | 救急指定病院・消防署周辺を通る徒歩ルートに寄せる | 不要 |
| バック音 | スーパー/コンビニの搬入時間帯のトラック後退（公道側から） | 不要 |

- **ロケハンは散歩1回**: 上記を地図アプリに5〜8ピン立てるだけ。暗騒音の目安は
  スマホの騒音計アプリで足りる（選定用途。本番の較正は借用騒音計で行う）
- 固有名詞の候補選定は大学・最寄り駅が分かれば地図上で絞り込める
