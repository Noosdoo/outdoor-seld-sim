## 5. 統制試行日の差分（8コマ版・遠慮なし構成時）

- 布陣: コーンで横2/3/5mを**メジャー実測**で設置／チェスト（自分）＋三脚H3-VR（1.5m間隔）／動画スマホは引きの全景／協力者が運転
- 手拍子1回で録音2台＋動画の3系統が一括同期
- 台本: 速度3段（**徐行/約20/約30。統制の上限は親計画どおり30km/h**。40km/h帯は
  交通量路C2の自然観測で充足=2026-08-13訂正）×横距離×向きで30通りを散らす。
  **最接近1.5m以内の再現は安全上禁止**
- スピードガンは立っている自分が無言で構える（読み値はスレートで記録）
- 体遮蔽A/B: 2台同時は同一イベントの**準直接比較**（1.5mの位置差＝距離・方位・
  反射の差が混入）。**クロスオーバーの規定（2026-08-13具体化）**: 同一の台本条件
  （速度×横距離×向き）を設置位置A/Bの両方で対にして反復し、ペア内の実施順は
  **AB/BAをペアごとに交互反転**（1ペア目A→B、2ペア目B→A、…）して順序効果を
  均衡化。分析は**同条件ペアの対応差のみ**用いる。1台のみの日は代表10試行を三脚/チェスト2回ずつ
- この日で 走行車20＋発進5＋EV/HV5＋キック20 = 50本（共通100本の半分）を消化。
  **静止/歩行対比20本も同一セッション内でAB/BA交互に消化する**（別日にすると
  音源差・環境差が交絡して比較が壊れる＝R7）

## 7. 中止・除外基準（安全と品質）

- 風速3m/s超: 収録中止（実施済みテイクは低域評価から除外・理由をメタデータに記録）
- 雨天: 中止（機材保護）。雨上がり路面は負例として歓迎
- 会話が明瞭に入った区間: 解析から除外（プライバシー規約）
- クラクション: 私有地のみ・短音・最小回数
- 最接近1.5m以内（critical層）の実車再現は行わない
- 自作/汎用ハーネスは初日リハで受入試験（落下防止テザー・±20°姿勢保持・歩行時の擦過音・ネジ緩み）

## 8. 注釈作業（帰宅後・半日）

- CSV列: `clip_id, event_id, trial, class, quadrant, t_start, t_cpa(±1s), n_car, 車種(EV/HV/ガソリン/大型), 速度(目視3段 or スピードガン実測), 横距離m, 風速, LAeq, 装着(三脚/チェスト), 区分(A〜E/歩行), 状態(静止/歩行), session`
- **1イベント1行**（1テイクに複数イベントがあれば行を追加。負例中の実在イベントも
  注釈する＝clip_id×event_idの複数行形式。2026-08-13改訂）
- 時刻は**原録音の時刻**で書く（切り出し後の時刻へはスクリプトが自動で移す）。
  切り出し後のCSVには `orig_file` / `cut_offset_s` / `scored` が自動付与される（2026-08-14追加）
- 手順: 手拍子で時刻原点合わせ → スレート音声（＋動画があれば±0.2秒級）で t_start/t_cpa 確定 → 記録紙を転記
- **しないこと**: フレーム単位の x,y,z・距離の手入力（不可能かつ設計上不要）

## 9. 変換と採点（帰宅後）

1. 変換: AmbiX 96kHz → 学習と同一のFOA形式（W,Y,Z,X/SN3D・24kHz）＋LAeq照合の絶対較正＋校正音による回転補正
1-b. **切り出し（2026-08-14追加）**: 原録音20〜30秒 → 解析用10秒。
   ```
   # イベント（最接近が10秒中の8秒地点に来る）
   python scripts/step19b_realsmoke_cut.py --mode event \
       --in out/realsmoke/converted --ann ann_orig.csv \
       --out out/realsmoke/clips --ann-out out/realsmoke/ann_clips.csv
   # 長時間負例（1秒重複つき分割・重複帯は前クリップ帰属で一意化）
   python scripts/step19_realsmoke_convert.py --in raw/neg.wav --laeq 42.0 \
       --laeq-window 10-70 --gain-only          # ← 全長を読まずゲインだけ出す
   python scripts/step19b_realsmoke_cut.py --mode negative \
       --in raw/neg.wav --ann ann_orig.csv --gain-db <上で出た値> \
       --out out/realsmoke/clips --ann-out out/realsmoke/ann_neg.csv
   # 注釈の機械検査（担当区間のタイル・必須列・横距離欠落を一発で見る）
   python scripts/step19c_ann_validate.py --ann out/realsmoke/ann_clips.csv --cut
   ```
2. 採点: **step19_realsmoke_convert.py → step19b切り出し → step19c検証 →
   step20_realsmoke_score_v2.py**（旧 step20_realsmoke_score.pyは欠陥確定につき
   実行時エラー化済み・使用禁止）。
   GT区分（横距離mからcritical/caution/safe）別の到達・抑制、リード（因果時刻）、
   象限、誤警告回数/時（イベント窓マスク・片側95%上限つき）
3. 使い道: ①v12の実環境成績 ②ablation4版を**同一クリップ・同一注釈・同一採点**で比較。
   差の判定は対応あり設計を活かす（2026-08-13改訂）: 二値の通知差=**McNemar検定**、
   リード秒=クリップ単位の**paired bootstrap**、誤警告率=露出時間ベースの**Poisson区間**。
   細かい点差は主張しない
4. **出さないもの（2026-08-14）**: 実測SELDスコア（0.1秒粒度の正解位置が無いため）。
   合成0.087との直接比較もしない。主要評価は**caution到達率1つ**を事前登録し、
   副次はHolm補正か記述統計扱い。**20〜30pt未満のarm間差は「検出できず」**と書く
