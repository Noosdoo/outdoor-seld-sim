## 4. 見つかった地雷（**本番前に必読**）

### ① `_run_v12_gen.py` に ABLATE を付けて流してはいけない
出力先が `out/dataset_outdoor_siren_v12` 固定で、かつ既存foaをスキップする再開設計。
そのまま流すと **(a) 全部スキップして何も生成されない**（基準が埋まっている場合）か、
**(b) 基準をablation音声で上書きする**（空の場合）。
→ arm専用の `scripts/_run_v12_abl_gen.py` を新設して回避した。

### ② サーバで `git pull` してはいけない
リポジトリは `*.flac` のみ gitignore で、**metadata/masks のCSVは追跡対象**。
サーバ側でこれらは生成物として存在するため、`git pull` は
「ローカルの変更を上書きする」と判断して **abort する**（実際に2026-08-15にabortした）。
→ 新規ファイルは **scp で個別に転送**する。`git checkout -f` や `git pull -f` は
**絶対に使わない**（基準データセットのCSVが消える）。

### ③ 学習sbatchは `server_sde/` にある
`server/` には v11 系しか無い。v12の学習は `server_sde/v12_g45_w3.sbatch`（job315）。
sbatchは `~/research/PSELDNet/PSELDNets` へ cd してそこの `_train_sde12.py` を呼ぶので、
**PSELDNets側の同期が前提**（2026-08-15時点では同期済みを確認）。
