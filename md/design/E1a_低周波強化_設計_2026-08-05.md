# E1a: 大型車の低周波強化による対照実験 — 設計（2026-08-05 01:10）

E0の結論（低周波は至近距離精度・通知選別を支える）を受けた次段。
問い: **音源側の低周波が実際に強い車（大型車・低速）では、距離精度と通知選別は
どこまで良くなるか**。「人間に聞こえる大きさは同じ、低音だけ物理的に増える」統制で測る。

## 1. 実験デザイン: ペア比較（E1-zero、学習なしから始める）

- **対象**: v11 val 1,200本のうち車を含むクリップ。**同一シーン（同一軌道・同一seed・
  同一の他音源）で、車音源だけ「大型車バリアント」に置き換えたペア**を新規レンダ
- **手法は差分加算**: 全シーン再レンダはせず、**追加低域成分（デルタ）だけ**を
  同一軌道でrender_mono→FOAエンコードし、既存flacに加算する
  - 根拠: レンダは線形（総和＝Σ音源＋雑音）なので、独立な追加成分の後付け加算は
    物理的に正当。サイレン等の他音源・背景は1サンプルも変わらない＝完全ペア
- **モデル**: まず既存 run3 をそのまま推論（E1-zero）。効果が見えたら学習込み
  （E1-full、v12系データセット新設）を検討

## 2. 大型車バリアントの仕様（E-R1文献で較正）

- 発火基本周波数 f0: 42Hz（乗用車4気筒アイドル相当）→ **50〜70Hz帯**
  （大型ディーゼル6気筒・低速走行1000〜1500rpm相当 = 63Hzオクターブ帯に一致）
- 追加成分は **250Hz以下に帯域制限**（低周波操作であることを純化。中高域の音色は不変）
- レベル規定: 対象車の**63Hzオクターブ帯が中周波帯（1kHz帯）と同等以上**になるよう
  デルタゲインを決める（E-R1「低速大型車は63Hz帯支配的」の再現）。
  実装時に数本で帯域実測し、恣意でなく文献状態の再現であることを検品する
- **統制（E-4/E-9の解決）**: 較正はdB(A)のまま＝A特性は40Hzで-34.6dB、63Hzで-26dB
  なので**dB(A)変化は+0.5dB未満に収まる**（実装時に実測して宣言値に含める）。
  つまり「人間の聞こえの尺度でほぼ同じ音量、機械には情報が増える」対照実験になる

## 3. 評価とGT の扱い（先に宣言）

- ラベル（位置・距離・クラス）: 幾何は不変なので**v11のGTをそのまま使う**
- 可聴性マスク: **元のマスクを両条件に共用**（A特性ベースでデルタの影響は微小。
  同一フレーム集合で比較することで検出率の分母を揃える）
- 採点: E0と同じ4点セット（クラス別可聴検出率 / 方向誤差 / 距離 / 通知v3.2）を
  ペアで比較。主指標は**車の至近≤5m距離誤差と安全車抑制率**（E0の効き所）

## 4. 事前登録ゲート（E1-zero実行前に宣言・変更しない）

- **H1（主）**: 大型車バリアントの車クラス至近≤5m距離中央誤差が素ペア比で改善する
  （改善幅の点推定と95%CIを報告。ゲート: 中央誤差 -0.03m以上の改善）
- **H2**: 通知層の安全車抑制率がペア比で悪化しない（-1.0pt以内）
- **H3（負の統制）**: 警告音クラス（サイレン等）の検出率・方向誤差はペア間で
  実質不変（±0.3pt / ±0.3°以内）——デルタ加算が他音源を汚していない証明
- 解釈制限（宣言）: 背景=ピンク（実街路より低域が軽い）のため、改善幅は上限値。
  また既存run3は「42Hz基本波の車」で学習しており、50-70Hz基本波は分布外
  → E1-zeroで効果が小さくても「学習すれば効く」可能性は残る（それはE1-fullの問い）
