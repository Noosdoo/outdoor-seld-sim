# E: 可聴外（低周波）帯域の活用 — 実装計画（2026-08-04）

教授提案E。F（歩きスマホ）は独立軸として棚上げ（研究が落ち着いてから）。
帯域スコープ: **25Hz〜12kHz**（超低周波<20Hzはマイク物理限界で不可、超音波>12kHzは
48kHz化が必要でE2=将来課題）。

## 0. 動機の書き直し（懸念E-7対応、卒論用ロジック）

- ❌「難聴者は聞こえないから低周波を使う」— 感音性難聴は**高周波から**落ちるのが典型で、
  低周波はむしろ残存しやすい帯域。この理屈は使わない
- ⭕「低周波は**誰にとっても**気づきにくい（マスクされやすく方向感が薄い）が、
  **物理的には最も遠くまで届く**帯域。機械はここを人間より上手に使える」
  = 人間の耳の代替でなく上位互換、という本研究の軸に接続
- 物理根拠は自前のISO 9613実装で定量化する（→E-M1）。大気吸収は周波数で桁が変わり
  低周波はほぼ無減衰、という表を自分のコードから出す（外部依存ゼロの動機資料）

## 1. 判明済みの事実（2026-08-04リサーチ）

- 特徴量経路: メルフィルタ f_min=20Hz（feature.py:34）→ 低周波はモデルに届いている。
  ただし n_mels=64 では **20〜94Hzが1ビン**（重低音帯=毎フレーム1スカラー）
- 大型車の実測: 低速（〜30km/h）では**63Hzオクターブ帯が支配的**（エンジン起因）、
  高速では中周波（タイヤ）に移る — 単一車両ノイズのスペクトル研究(ScienceDirect 2024)
- 風雑音: **20〜200Hzに集中**（〜100-300Hzまでフラット、以降減衰）。
  風防で100Hz付近を約14〜23dB、ピークで21〜24dB抑えられる（ASA POMA実測 / INTERNOISE2014）
  → Eの標的帯域と風の帯域は正面衝突するが、風防+風速記録で管理可能
- H3-VR: 本体に**Lo Cutフィルタ設定がある**（レンタル機で必ずOFF確認。ONのままだと
  低域検証が全滅する）

## 2. 発見した追加懸念 E-9（重要・設計判断が要る）

パイプラインの音圧・SNR・可聴性ゲートは **A特性（frame_spl_a）** ベース。
A特性は40Hzで約-34.6dBも減点するため、**低周波だけの音はゲートに「ほぼ無音」扱いされる**:
- 可聴フレーム判定（SNR≥0dB）に低周波成分が反映されない
  → 低周波起因の検出は「不可聴なのに当てた」扱いになり採点が歪む
- E1で低周波を足しても dB(A) 指定の音源レベルはほぼ変わらない
  → 「エネルギー等価統制」をdB(A)で定義すると低周波は事実上無制限に盛れてしまう
**設計判断**: E1着手前に (a)可聴性ゲートをZ特性(フラット)併記にするか
(b)「A特性可聴性はそのまま・低周波寄与は別軸で採点」にするか を決めて事前登録する。

## 3. フェーズ計画

| E-R1 | 大型車・バスの低周波スペクトル実測文献（63Hz帯の実測レベル、速度依存）→E1音源較正の根拠 | Opus |
| E-R2 | 低周波・infrasoundによる車両検知の先行研究（無人センサ・軍事/国境監視系に文献群がある）→関連研究接続 | Opus |
| E-R3 | 風雑音対策の定量（風防の減衰実測・風速と雑音レベルの関係）→実録プロトコル反映 | Opus |

### E0: 低周波依存度の無学習測定（今週末、費用0円）
- 既存 val 1,200本にゼロ位相ハイパスフィルタ（カットオフ 50 / 100 / 200 Hz の3条件）を
  かけ、**run3モデルそのまま**で推論 → 素の入力との差分を採点
- 出力: カットオフ別の SELD / クラス別検出率 / 距離MAE / 検出開始距離 の劣化曲線
  =「現行モデルは低周波をどれだけ使っているか」の事実
- 事前登録（実行前にゲート宣言）: 予想=車クラス（エンジン42Hz+倍音）が最も劣化。
  「HPF100Hzで車の検出率が-1pt以上落ちれば低周波寄与あり」等を実行前に固定
- 統制の宣言: フィルタ後の再正規化はしない（エネルギー減少込みが「低周波を失う」の定義）
- 新フォルダ出力（out/e0_lowfreq_probe/ 等）、既存成果物は不変更

### 実録連携（8月中旬、実録スモークに相乗り）
- プロトコル追記: ①風防必須+風速メモ ②H3-VR Lo Cut OFF確認 ③大型車通過の
  自然遭遇を意識的に収録 ④静穏時の暗騒音も収録（低域の実録ノイズフロア実測）
- 目的: 「実環境の20〜100Hz帯のSNRがどれだけ残るか」を実測 → **E1のGO/NO-GO判定材料**
  （合成には風がない=E最大の懸念E-2は、実録数字でしか潰せない）

### E1: 低周波の早期検知価値の測定（実録後・GO判定が出た場合のみ）
- E-R1の実測スペクトルで「大型車バリアント」音源を較正（63Hz帯強化、恣意性排除）
- 交絡対策（E-4）: 帯域配分のみ変えた対照音源（総音圧の定義はE-9の設計判断に従う）
- まず現行64メル（20Hz床・低域1ビン）のままで学習し「1ビンでも効くか」を測る。
  メル数変更（事前学習と非互換）は結果が出た場合のみ検討、基本は将来課題
- 主要評価: 初検知距離・リードタイムの差（「低周波は何mの早期検知を買うか」）
- 新データセット・新run・事前登録ゲート。ストレージ残量を生成前に確認

## 4. やらないこと（スコープ外を先に宣言）

- 超音波/48kHz化（E2）・メル数変更を伴う特徴量再設計 → 将来課題
- 低周波の「方向」推定の主張（実アレイでは方向手がかりが弱い。検出・距離に限定）
- F（歩きスマホ）との同時実装（スマホは低域が最も苦手=二重苦のため独立軸厳守）

## 5. 卒論での置き場所

「低周波帯域の寄与分析」1節: E-M1物理表（動機）→ E0依存度曲線（現状の事実）→
実録の低域ノイズフロア（現実の壁）→（GOなら）E1早期検知距離（価値の定量）。
E0止まりでも「現行モデルの帯域依存を初めて定量した」として成立する構成にする。
