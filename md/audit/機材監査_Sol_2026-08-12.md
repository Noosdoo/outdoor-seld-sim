# 機材監査記録（Sol・2026-08-12）

# 監査判定：条件付き合格

添付証拠だけで審査すると、構成の中核である「H3-VRを借用、次にレンタル」は妥当で、H2nを除外した判断も正しい。一方、R3～R5の一部、超音波試験の成立性、付属品、予算上限が未確定であり、現状のまま本番投入できる完成度ではない。

## R1～R5の充足状況

| 要件 | 監査結果 | 判断理由 |
|---|---|---|
| R1 4ch FOA・W/X/Y/Z | 基本的に充足 | Z軸必須という要件に対し、W/X/YしかないH2nを不可とした論理は正しい。H3-VRで4ch方向収録する構成も一貫している。ただし本番前に、実ファイルが期待するAmbiXのチャンネル順・正規化・向きであることをパイプライン入力まで確認する必要がある。 |
| R2 96kHz | 形式上充足、実効性は未確定 | 96kHz設定、Lo Cutオフは明示されている。ただし96kHzで標本化できることと、仕様外の40kHzが十分なSNRで録れることは別問題。添付自身も40kHz感度を無保証としており、ここは実機試験が必須。 |
| R3 固定ゲイン・風防・三脚/チェスト | 一部未確定 | ハーネス、変換ネジ、三脚の方針はあるが、固定ゲインの具体設定、AGC・リミッター等の無効化、全チャンネル同一条件の記録手順がない。Rentioの風防は「要確認」のままで、R3を確定充足していない。 |
| R4 絶対較正手段 | 条件付きで充足 | 本件で定義された「A特性騒音計によるLAeq読み上げ」方式自体には合う。ただし例示された騒音計の記載はA特性・測定範囲・校正サービスまでで、LAeq積分表示の有無が証拠上不明。瞬時dBA値はLAeqの代わりにならない。方位校正音の発生源・配置・手順も未記載。 |
| R5 40kHz統制送信源 | 周波数だけ充足、ピング要件は未証明 | HC-SR04等が40kHzであることは示されているが、送信持続時間、波数、繰返し周期、音圧、指向性、距離、方位・仰角の設定がない。「Arduinoでトリガできる」だけでは統制送信源として十分とは証明されない。 |

特に、H3-VRでFOAと96kHzを同時に使う実際の収録モードについて、短い試験ファイルを作り、次を機械的に確認すべきである。

- 4チャンネルでW/X/Y/Zが欠けていない
- サンプルレートが全チャンネル96,000Hz
- 想定するAmbiX形式と既存モデルの入力規約が一致
- 固定ゲイン、Lo Cutオフ、不要な自動処理なし
- 風防・チェスト装着状態でもチャンネル欠落、振動、クリップがない

## 調達順序とレンタル日数

借用→レンタル→中古購入という優先順位は妥当である。Rentio 4,380円に対し、メディアリースを3泊4日使うと約1万円になるという比較も整合している。

「3セッション＋リハを7泊8日で行う」点も、3セッションをDay1早朝、Day1日中、Day2日中の3収録ブロックと解釈すれば矛盾しない。注釈半日はレコーダーを必要としないため、1回のレンタル期間内に収まる。

ただし、次の点は未解決である。

- 風速3m/s未満という条件に対する予備日
- 雨天・対象車両不足・自然発生音不足への振替日
- 到着時に故障や欠品が判明した場合の交換日数
- 返却日を含む実使用可能日数
- H3-VRに代替機なしという単一障害点

また、「3回以上使うなら中古検討」は価格だけでは閾値が早すぎる。Rentioを別期間に借りる場合でも、

- 3回：13,140円
- 4回：17,520円
- 5回：21,900円

であり、中古下限約18,000円との単純な損益分岐は概ね5回目である。3～4回で中古を選ぶなら、日程自由度、再販価値、レンタル在庫リスクを金額化した根拠が必要になる。

## バットディテクター撤回

購入撤回そのものは妥当である。可聴化デモと取得済み信号の解析は、E2ミニのソフトウェアヘテロダインで代替できる。

ただし、「受信の保険」の代替にはならない。ソフトウェアはH3-VRが取得した同じ波形を処理するだけなので、H3-VRに40kHz感度がなく信号を取得できなかった場合、失われた信号を回復できない。この部分の記述は論理的に誤っている。

したがって、バットディテクターを買う必要はないが、少なくとも本番前に次の判定が必要である。

1. 送信源が実際に40kHzを送信していることを別手段で確認する。
2. 本番と同じH3-VR・風防・距離・ゲインで40kHzピークを検出する。
3. 無送信対照との差、4チャンネルそれぞれのSNR、クリップ有無を確認する。
4. 合格基準を先に数値化する。
5. 不成立なら、独立受信系の借用等を行うか、40kHz試行を成立済みとは扱わない。

## 予算監査

文書内の丸め値で再計算すると、風防等が無料という前提では概ね正しい。

| 構成 | 再計算 |
|---|---:|
| 借用成立 | 2,000＋1,500＋1,500＝5,000円 |
| レンタル1回 | 4,380＋3,300＋2,000＋1,500＋1,500＝12,680円 |
| レンタル2回 | 8,760＋3,300＋2,000＋1,500＋1,500＝17,060円 |

「約12,000～17,000円」は丸めとして大きな誤りではない。ただし、これは上限予算としては不完全である。

- 風防3,000円と三脚・コーン等500円を加えると、レンタル1回で16,180円
- 同じくレンタル2回では20,560円
- 風速を記録し3m/s超を除外するのに、風速計または同等の測定手段が機材・予算にない
- 配送料、交換対応、追加電池等の予備費も明示されていない

したがって、標準構成の安全側上限は少なくとも「約20,600円＋風速測定手段＋諸費用」とするか、風防・三脚・風速計が確実に借用・同梱されることを明記すべきである。

## 合格条件

本番前に以下を完了することを条件とする。

- Rentioまたは借用品の風防、電池、SDカード、取付ネジ等の同梱品を確定する。
- FOA 4ch・AmbiX規約・96kHz・固定ゲインを実ファイルで検証する。
- 騒音計のLAeq機能、積分時間、校正状態、読み上げ手順を確定する。
- 方位校正音の発生源・位置・実施手順を定義する。
- HC-SR04系のバースト長、繰返し周期、距離、方位、指向性を規定し、40kHz実効SNRの事前試験を通す。
- 風速測定手段、故障交換日、天候予備日を計画へ追加する。
- 風防等を含む実支出上限へ予算を修正する。

中核機材の選択をやり直す必要はないが、上記は収録成立性を左右する未確定事項であるため、判定は**条件付き合格**とする。
