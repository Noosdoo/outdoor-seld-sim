## 重大度付き指摘

### [中] no-doppler の発音終了境界が音声窓と一致していない

- `labels.py:56`
  ```python
  active &= t_nd <= source_active_until
  ```
- 添付された窓規約は `step11_v9_render.py:752` の
  ```python
  (tgrid >= t_on) & (tgrid < t_off)
  ```
  であり、終了側は半開区間である。

したがって `t_nd == source_active_until` のフレームでは、ドライ音声は窓外なのにラベル行が残る。これは「厳密に同じ時刻規約」という主張を満たさない。

再現手順：静止音源で伝搬遅延を0.05秒、`label_res=0.1`、フレーム中心0.25秒、`t_off=0.20`秒に設定する。`t_nd=0.20`となり、音声窓は除外するが現コードはラベルを含める。

修正条件：no-doppler 分岐を `< source_active_until` にするか、音声窓を閉区間に統一して境界テストを追加する。既定分岐にも同じ `<=` があるが、そちらは既存挙動なので別途互換性を判断すべきである。

### [中] スモークは「全経路の既定不変」を証明していない

`scripts/_ablate_smoke.py:50` で `load_plan_v12conf()[0]` の1クリップだけを生成している。さらに検査対象は次に限定される。

- 既定回帰はFOAファイルだけ
- ラベル検査は `cls=0` のサイレンだけ
- metadata の既存confとの回帰比較なし
- masks、scene、直接音ステム、鏡像ステムを未検査
- no-doppler のラベル変化は表示するだけで、正しい期待値をassertしない
- ext系、歩行マイク、step19、ADPITを未検査

再現可能な検証力の反例として、全モード共通でメタデータの方位角を1度ずらしても、FOAハッシュは変わらず、各条件のサイレン行同士も同じようにずれるため、このスモークは通り得る。ext専用レンダ経路に欠陥を入れた場合も先頭coreクリップだけでは検出できない。

### [中] step19距離ラベルとADPITへの波及は添付証拠から監査不能

対象ファイルや実行結果が添付されていないため、計画4.5節の「無変更で整合」はコード上確認できない。

期待される挙動は次のとおり。

- 共通フレームの距離値・方位値：全条件で従来の放射時刻ベース
- no-doppler：一定遅延規約によるmetadata行集合の変化を距離ラベルとADPIT activityにも反映
- no_1r/no_airabs/no_ground：非ゲート音源の行集合は不変
- 車：SNR可聴ゲートの変化に伴う行集合の変化を下流にも反映

metadata、距離ラベル、ADPIT間の `(clip, frame, class, track)` キー一致検査が必要である。

### [低] 「ビット一致」は実際にはSHA-256先頭64 bit一致

`scripts/_ablate_smoke.py:27` は `hexdigest()[:16]` しか比較していない。実用上の衝突確率は極小だが、数学的なビット一致証明ではない。`read_bytes()` の直接比較、または少なくともSHA-256全64桁を使うべきである。

### [低] no_1r時もsceneの予測値は1/rを仮定したまま

`step11_v9_render.py:752-754` の `recv_pred_db` は常に `mean(1/dist²)` から計算される。`no_1r` ではレンダ側が幾何減衰を外すため、この予測値は条件の物理を表さない。

例えば距離10 m一定なら、コードは約−20 dBの幾何減衰を予測するが、no_1rのレンダにはその減衰がない。ゲートには使われていないので音声・ラベルの正否には直結しないが、sceneの診断値として誤解を招く。mode対応式にするか、`full_physics_recv_pred_db` など意味を限定すべきである。

## 監査の問いへの回答

1. **既定経路の不変性**

   添付された共通経路については、未設定時に `render_flags()` がすべて `True`、`ground_enabled()` が `True`、sceneの追加フィールドも出ないため、差分は旧経路と意味的に同じである。実物FOAとの一致も強い回帰証拠である。

   ただし1クリップのFOAだけでは、ラベル・マスク・ext系・歩行マイクを含む「全経路のビット同一」は証明できない。結論は「検査されたcoreクリップのFOAは一致。全経路は未証明」。

2. **リファクタの等価性**

   合格。旧コードの

   - `finite = np.isfinite(te)`
   - 有限値のmedian
   - `np.where(..., np.inf)` 後の `argmin`
   - タイ時に先頭を選ぶNumPyの挙動
   - 有限解なしなら全NaN

   がそのまま `_nodop_ref_from` に移されている。中央値・タイ処理を含め、同じ入力に対して厳密に同挙動である。

3. **no-dopplerの音・ラベル整合**

   参照点と遅延値は、現在のstep11経路では一致している。両者とも同じサンプル格子、`solve_emission_times`、`_nodop_ref_from`、median、argminを使い、数値検算も静止・歩行の双方で一致している。

   到達ゲートも音声側の `np.isfinite(te)` とラベル側の `np.isfinite(az)` により通常シーンで維持される。

   ただし終了境界の `<=` と `<` が一致しないため、「発音区間まで厳密に同じ」は不成立。また、数値検算は共通ヘルパーを通るため、回帰確認としては有効だが独立オラクルではない。

4. **副作用の網羅**

   コードから読み取れる意図は概ね正しい。

   - no_doppler：波形、全クラスのSNRマスク、発音行集合が変わり得る
   - no_airabs：波形・SNRマスクが変化。非ゲートクラスのラベルは不変
   - no_1r：波形・SNRマスクが変化。特に遠方車の可聴行が増えるのは意図した帰結
   - no_ground：反射込み波形・SNRマスクが変化。直接音は不変
   - 全条件：共通フレームの方位・距離計算経路は不変
   - 車：どの物理条件でもSNR閾値を越えるフレームが変わればmetadata行も変化し得る

   step19とADPITについては、上記行集合の波及が必要だが証拠不足で確認できない。

5. **スモークの検証力**

   「1本が生成できる」「4条件の最終FOAが互いに異なる」「対象サイレンの一部ラベル性質」は確認できている。しかし、物理スイッチの正しさや全経路不変の証明としては不足している。

   最小追加ケースは以下。

   1. ext系の固有経路を通すクリップ  
      列車多点音源・キック・バイクを、可能なら1クリップ、無理なら固有レンダ経路ごとに1本。ABLATE未設定でFOA・metadata・masksを既存実物と比較する。

   2. 歩行マイク＋no-doppler  
      到達前区間、有限到達区間、`t_nd == t_off` 境界を含め、実レンダと期待ラベル行を独立計算でassertする。

   3. 車1本の下流統合  
      full/no_1r/no_dopplerをstep19・ADPITまで通し、metadataとのキー集合一致と、共通行の距離値不変をassertする。

完全合格の条件は、終了境界の統一、上記最小回帰の追加、step19/ADPITのキー整合確認である。
