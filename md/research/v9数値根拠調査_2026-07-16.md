# v9設計値のresearch結果（2026-07-16、第2弾）

未確定だった設計値を規格・文献で確定。出典は各節末。

## 1. 踏切警報音の仕様（合成の設計図）

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| 周波数 | **700Hz±15Hz と 750Hz±15Hz の2音交互**（半音差の不協和音） | 旧国鉄1962年標準化、現行踏切警報機の規格 |
| 変調速度 | **毎分130回±5回**（約2.17Hz） | 同上 |
| 音量 | **80dB @ 1m が通説値**（遮断桿降下後は減音される運用あり） | 報道記事＋Wikipediaの傍証（一次規格文書は未確認→**設計値扱い**。2026-08-06第8回監査で「標準値」表記を訂正） |
| 音源の性質 | **固定音源**（動かない）。エンジン的には速度0の軌道として扱える | — |

- ジッタ設計: 周波数±15Hz（規格公差そのまま）、変調±5回/分（同）、音量は
  現場調整幅を考慮し 75-85dB
- 帯域は700-750Hz＝warning4種とも車とも住み分け良好
- 危険定義: 踏切は「警報が鳴っている間に接近する」こと自体が危険 → 警告音と同じ
  「全イベント通知」で扱う（接近判定は不要）

## 2. 車のタイヤノイズ（合成への追加仕様）

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| スペクトルピーク | **800-1200Hz（中心約1kHz）** | multi-coincidence peak（タイヤ/路面音響の確立した知見） |
| エネルギー帯域 | 600-2000Hz（>40km/hで支配的） | 単一車両の周波数分析研究 |
| 速度依存 | レベル ∝ 約30log10(v)、**スペクトル形状は速度に依らない** | 同上 |

- v9実装: エンジン音（低域）に加え、1kHz中心・600-2000Hzの帯域ノイズ成分を追加。
  混合比はジッタで振る。**速度→音量の結合は入れない**（交絡回避の決定どおり。
  ただし「形状は速度不変」という知見により、音量だけ独立に振っても物理的に破綻しない
  ことが裏付けられた）
- これで車 vs 警告音の帯域重なりが現実的になる（beep 1kHzとタイヤピークが重なる=
  現実に存在する難しさが正しく入る）

## 3. 暗騒音レベルの軸（環境省の環境基準でアンカー）

| 環境 | レベル | 根拠 |
| --- | --- | --- |
| 住居地域・夜 | ≤45dB | 環境省 騒音に係る環境基準（A地域） |
| 住居地域・昼 | ≤55dB | 同上 |
| 道路沿道（2車線超）昼 | ≤60dB | 同上（道路に面する地域） |

- **v9の暗騒音軸: 40〜65dB(A) の一様サンプル**（静かな住宅街の夜〜幹線沿いの昼を
  カバー。基準超過側も少し含めて検出限界カーブの右端を測る）
- 絶対較正: デジタル振幅⇔dB SPLの対応を1つ固定し、音源（法規レンジ）と暗騒音
  （この軸）を同じ物差しに載せる。8月実測は「実際の街がこのレンジのどこか」の確認に使う

## 4. 必要本数の設計（統計的な逆算）

主要な分析マス目と必要数（イベント比率の推定に各マス≥20イベント、
フレーム指標は数千フレーム/マスで十分過ぎるため制約はイベント側）:

| 分析 | マス目 | val/testで必要 |
| --- | --- | --- |
| 通知評価 | 危険3層（重大/注意/安全）× 歩行2 | 6マス×20 = 120クリップ以上 |
| 検出限界カーブ | 暗騒音4帯 ×（車の可聴多様性はクリップ内で自然に分布） | 上と共用可 |
| クラス別知覚評価 | 6クラス × 歩行2 | 警告音は1クリップ1-2個出現するので約160本で各マス≥20 |

**提案: 総数960本 = train 640 / val 160 / test 160**（fold1/2/3）
- 車の横距離は危険3層が均等になるよう層別サンプリング（0.5-1.5m / 1.5-3m / 3-15m）
- 音源数の比率: 1音源40% / 2音源45% / 3音源15%（警告音≤2＋車。車のみ=約30%と両立
  するよう乱数設計）
- 歩行:静止 = 50:50
- 生成コスト見込み: 960本 × 約9秒 ≈ **2.5時間**（v8実績から。ボトルネックではない）
- 学習コスト: train640本 → 80ステップ/epoch、100epochでT4約1時間

## ⚠️訂正（2026-07-17、本人の試聴指摘→一次情報で確認）: 踏切警報音の構造

本文書の「700/750Hz**交互**」は誤り。一次情報（鉄道総研 人間科学ニュース200号、
Wikipedia踏切警報機）による正しい構造:
- 700Hz±15 と 750Hz±15 は【**同時に鳴る和音**】（半音違いの濁った不協和音。
  片方の故障に音色変化で気づける冗長設計）
- 毎分130±5回は【**オン・オフの断続回数**】（変調故障→連続音、発振故障→澄んだ音、
  という故障モード記述が正常時=断続・濁り の裏付け）
- 音色は電鐘（金属打音）の波形分析を下敷きに開発 → 倍音と打音的減衰が本質
- 周波数値・毎分130回・80dB@1m の通説値自体は正しかった（構造だけが誤り。※「規格値」表記は2026-08-06第8回監査で訂正: 一次規格文書は未確認のため規格値とは呼ばない）

対応: src/outdoor_seld/alert_sounds.py に make_crossing_v2 を追加（旧make_crossingは
v9再現性のため凍結）。修正版はデータセット v9.1 として別フォルダに再生成予定。
併せて自転車ベルに JIS D 9451 の「引き打ちベル（チリリンチリリン）」型
make_bike_bell_ring を追加（既存の単打「チーン」と2種構成へ）。
